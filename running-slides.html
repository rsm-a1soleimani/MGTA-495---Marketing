Configuration

Adding the Page in _quarto.yml

The decision

The running page needed to appear in the shared navbar without inheriting the site's default content styles. The nav entry is just two lines in _quarto.yml — but the page-level format override (self-contained: false) keeps it linked to the shared site_libs/ assets rather than inlining everything.

# _quarto.yml — site-wide config
project:
  type: website
  output-dir: docs

website:
  title: "Arman Soleimani"
  navbar:
    left:
      - href: index.qmd
        text: About
      - href: resume.qmd
        text: Resume
      - href: projects.qmd
        text: Projects
      - href: running.qmd    # ← adds Running to every page's nav
        text: Running

format:
  html:
    theme: [cosmo, brand]
    css: styles.css   # Playfair + Barlow loaded site-wide
1

Two lines, everywhere

Adding running.qmd here is all it takes for the Running link to appear in the navbar on every page automatically — no per-page nav configuration needed.

2

Theme: cosmo + brand

Quarto stacks themes — cosmo is the Bootstrap base, brand layers on top. styles.css then imports the custom font pair (Playfair Display + Barlow Condensed) that carries across every page.

3

output-dir: docs

GitHub Pages reads from docs/, so every quarto render + push deploys the live site automatically — no separate CI step needed.

Source File

Why the Whole Page Lives in One {=html} Block

The decision

Quarto would normally process the file as Markdown and strip out custom HTML. Putting everything in one {=html} block tells Quarto to pass it straight to the browser untouched — so the custom styles and layout work exactly as written.

---
title: ""              # suppresses the auto-generated <h1>
format:
  html:
    self-contained: false # keep shared site_libs/ linked, not inlined
---

```{=html}
<style>
  /* page-scoped CSS — only affects running.html */
  body { background-color: #2C4A2E; }
  .hero-video-container { width: 100vw; ... }
</style>

<div class="hero-video-container"> ... </div>
<div class="running-content"> ... </div>
```
1

title: ""

Blank title suppresses the auto-generated <h1> so the video fills the screen immediately instead of being pushed down by a heading.

2

self-contained: false

Keeps the page linked to shared site_libs/ assets (navbar JS, Bootstrap) rather than inlining them. Without this, the navbar breaks.

3

Styles stay on this page only

CSS inside the block only renders in running.html — the dark green background doesn't leak to other pages on the site.

CSS Challenge

Breaking Out of Quarto's Layout Grid

The problem

Quarto adds side margins to every page by default. To make the video go edge-to-edge, I zeroed out those margins in the layout grid, then expanded the video div beyond its container using a standard CSS trick.

/* Zero out Quarto's 4-column grid: [left-margin][sidebar][content][right-margin] */
.page-columns {
  grid-template-columns: 0 0 1fr 0 !important;
  padding-left:  0 !important;
  padding-right: 0 !important;
}

/* Container-escape: width to 100vw, shift left to re-center */
.hero-video-container {
  position: relative;
  width: 100vw;
  left: 50%;
  transform: translateX(-50%);
  height: 60vh;
  overflow: hidden;
}

/* Fill the box without distorting the video */
.hero-video-container video {
  position: absolute;
  top: 50%;  left: 50%;
  transform: translate(-50%, -50%);
  width: 100%;  height: 100%;
  object-fit: cover;
}
1

grid-template-columns: 0 0 1fr 0

Quarto's layout is a four-zone grid — margins on both sides, a sidebar slot, and the content column. Setting the three outer zones to 0 removes the side gaps so content can reach the edge.

2

100vw + translateX(-50%)

Sets the video to the full browser-window width, then shifts it left by half so it re-centers on screen. This is the standard way to break an element out of a constrained parent in CSS.

3

object-fit: cover

Scales the video to fill its box without distortion — cropping the edges if needed. Same behavior as background-size: cover on an image.

CSS Challenge

Keeping the Navbar Intact on a Dark Page

The problem

Making the page dark green also turned the navbar green. I added a CSS rule that targets the navbar specifically and tells it to keep its original color — everything else on the page still gets the green background.

/* Page background — applies to everything including the navbar */
body, .quarto-container, #quarto-content, .page-columns {
  background-color: #2C4A2E !important;
  overflow-x: hidden;
}

/* Rollback: force the navbar to its original dark-theme color */
#quarto-header,
#quarto-header *,
.navbar,
.navbar *,
.navbar-brand,
.nav-link,
.navbar-nav .nav-link {
  color: #343a40 !important;
}

/* Content text on the green background: switch to cream */
p, li, span, .running-content { color: #f5f0e8; }

/* Headings inside the content section */
.running-content h2, .running-content h3 {
  color: #f5f0e8;
  letter-spacing: 0.08em;
}
1

Why !important

Bootstrap's built-in styles have high priority, so a normal CSS rule won't override them. !important forces my rule to win — and since it's scoped to this page's block, it doesn't affect other pages.

2

#quarto-header *

The * targets every element inside the navbar — links, site title, search icon. Without it, those child elements would still inherit the green from the body rule.

3

.running-content wrapper

All the text and embeds sit inside this div, capped at 600px wide and centered. Keeps the content readable and prevents style rules from accidentally affecting other parts of the page.

Design Detail

The Strava Button

The approach

It's a regular HTML link styled with CSS to look like a Strava button — no library needed. The three things that make it feel branded: the exact Strava orange, sharp corners instead of rounded, and a hard drop shadow.

<!-- HTML -->
<a href="https://www.strava.com/athletes/53854051"
   target="_blank"
   class="strava-btn">My Strava</a>

/* CSS */
.strava-btn {
  display: inline-flex;
  align-items: center;
  background-color: #D4511E;    /* Strava's exact brand orange */
  color: white !important;
  padding: 12px 24px;
  border-radius: 0;              /* sharp corners — intentional */
  box-shadow: 3px 3px 0 #1C1915; /* hard-edged, zero-blur shadow */
  font-family: 'Barlow Condensed', sans-serif;
  letter-spacing: 0.15em;
  text-transform: uppercase;
  font-weight: bold;
  margin-bottom: 48px;
}
1

#D4511E — Strava's orange

Pulled directly from Strava's brand guidelines so the button reads as "Strava" before anyone reads the text.

2

border-radius: 0 (sharp corners)

Rounded corners feel like a standard web app. Sharp corners match the athletic, direct tone of the page.

3

box-shadow: 3px 3px 0

Zero blur makes the shadow a hard-edged solid copy rather than a soft glow — gives the button a stamp-like, graphic quality.

Third-Party Embeds

Embedding Instagram & YouTube

The approach

Each platform gives you an official embed code to copy into any webpage. I pasted both into the {=html} block — that's required because Quarto strips <iframe> and <script> tags from regular Markdown sections.

<!-- Instagram: placeholder blockquote + runtime script -->
<blockquote
  class="instagram-media"
  data-instgrm-permalink="https://www.instagram.com/p/DWO0y71kTFG/"
  data-instgrm-version="14"
  style="width:100%; max-width:540px;">
</blockquote>
<script async src="//www.instagram.com/embed.js"></script>

<!-- YouTube: iframe at 9:16 (portrait Short dimensions) -->
<iframe
  width="315" height="560"
  src="https://www.youtube.com/embed/vY5WS2eHcCo"
  allow="accelerometer; autoplay; clipboard-write;
         encrypted-media; gyroscope; picture-in-picture"
  allowfullscreen>
</iframe>
1

Instagram: placeholder + script

The blockquote is just a placeholder. Instagram's embed.js script loads on page open, finds it, and replaces it with a live interactive post.

2

315×560 (portrait dimensions)

YouTube Shorts are filmed vertically. These dimensions match the 9:16 ratio so the video displays correctly — not as a widescreen rectangle with black bars on the sides.

3

Why {=html} is required here

Quarto removes <iframe> and <script> tags from regular Markdown sections. Inside a {=html} block, the content goes directly to the page — nothing gets stripped.

Visual Design

Design Choices

The intent

The palette is deliberately tight — four colors, used consistently. The Strava orange appears only on the CTA button and headings, so it always signals something actionable. Forest green and cream do all the atmospheric work without competing for attention.

Forest
#2C4A2E
Cream
#F5F0E8
Strava
#D4511E
Ink
#1C1915

Typography — styles.css

  • Playfair Display — h1/h2/h3. Serif weight gives an editorial, magazine quality.
  • Barlow Condensed — body, labels, buttons. Narrow and efficient, feels athletic.
  • Wide letter-spacing (0.08–0.15em) on all uppercase labels — keeps short words from feeling cramped.
  • Defined once in styles.css, inherited by all pages including running.

Why these choices?

  • Forest green evokes endurance and outdoors without being a cliché sports color (red, blue, black).
  • Cream instead of white softens contrast — easier on the eyes against dark green, warmer overall tone.
  • A single accent color means it always draws attention — no competition between multiple bright elements.
  • Sharp corners throughout reinforce the direct, no-nonsense tone of competitive running.
Summary

What This Page Demonstrates

The running page shows how far a single {=html} block can take a Quarto page — from the default cosmo layout to something that looks like an entirely different site, while still sharing the same navbar, fonts, and deployment pipeline.

01

Full design control inside Quarto's structure

The shared navbar, routing, and GitHub Pages deployment all come from _quarto.yml. The {=html} block handles everything visible on the page — the two layers don't interfere.

02

CSS overrides as the escape hatch

The grid override, container-escape technique, and navbar rollback are the three patches needed to break Quarto's defaults. Each one is targeted — nothing is blanket-reset.

03

Content-first framing

Every design decision — the palette, the portrait embed dimensions, the sharp button corners — was made to serve the content and the brand relationships, not to demonstrate technical complexity.

04

Personal + professional in one page

Brand partnerships (Under Armour, GU Energy) sit alongside a live Strava link — the page functions as both a portfolio piece and an active hub for running activity.
