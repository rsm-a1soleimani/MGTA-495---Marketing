Configuration

Adding the Page in _quarto.yml

The decision

The running page needed to appear in the shared navbar without inheriting the site's default content styles. Adding it to the nav is two lines — but self-contained: false keeps it linked to shared assets.

website:
  navbar:
    left:
      - href: index.qmd
        text: About
      - href: running.qmd   # adds Running to every nav
        text: Running

format:
  html:
    theme: [cosmo, brand]
    css: styles.css   # Playfair + Barlow site-wide
1

Two lines in the nav

Adding running.qmd here puts the Running link in the navbar on every page — no per-page configuration.

2

theme: cosmo + brand

cosmo is the Bootstrap base; brand layers on top. styles.css imports the custom font pair used across the whole site.

3

output-dir: docs

Rendered files go to docs/ — the folder GitHub Pages reads. Every push auto-deploys the live site.

Source File

The running.qmd File

The decision

Quarto would process the file as Markdown and strip custom HTML. Putting everything in one {=html} block tells Quarto to pass it straight to the browser untouched.

---
title: ""              # suppresses the auto <h1>
format:
  html:
    self-contained: false
---

```{=html}
<style>
  body { background-color: #2C4A2E; }
</style>

<div class="hero-video-container"> ... </div>
<div class="running-content"> ... </div>
```
1

title: ""

Blank title suppresses the auto <h1> so the video hero fills the screen immediately — no heading gap above the fold.

2

self-contained: false

Keeps the page linked to shared site_libs/ assets. Without this, the navbar and search break.

3

CSS scoped to this page

Styles inside the block only render in running.html — the dark green background doesn't leak to other pages on the site.

CSS Challenge

Breaking Out of Quarto's Layout Grid

The problem

Quarto adds side margins to every page by default. To make the video go edge-to-edge, I zeroed out the grid columns and expanded the video div beyond its container.

/* Zero out Quarto's 4-column grid */
.page-columns {
  grid-template-columns: 0 0 1fr 0 !important;
  padding-left: 0 !important;
  padding-right: 0 !important;
}

/* Escape the container to full viewport width */
.hero-video-container {
  width: 100vw;
  left: 50%;
  transform: translateX(-50%);
  height: 60vh;
}

video { object-fit: cover; }
1

grid-template-columns: 0 0 1fr 0

Quarto's layout is a four-zone grid. Setting the outer three to 0 removes the side gutters so content reaches the edge.

2

100vw + translateX(-50%)

Sets width to the full browser window, then shifts left by 50% to re-center. The standard CSS escape from any constrained parent.

3

object-fit: cover

Scales the video to fill its box without distortion — same behavior as background-size: cover on an image.

CSS Challenge

Keeping the Navbar Intact

The problem

Making the page dark green also turned the navbar green. A targeted CSS rule tells the navbar to keep its original color — everything else on the page still gets the green background.

/* Dark green for the whole page */
body, .quarto-container, #quarto-content {
  background-color: #2C4A2E !important;
}

/* Navbar rollback */
#quarto-header,
#quarto-header *,
.navbar, .nav-link {
  color: #343a40 !important;
}

p, li, span { color: #f5f0e8; }

.running-content {
  max-width: 600px; margin: 0 auto;
}
1

Why !important

Bootstrap applies colors with high specificity — !important forces the override. Page-scoped, so it doesn't affect other pages.

2

#quarto-header *

The * catches every child — links, brand text, search icon — so none inherit the green from the body rule.

3

.running-content

Caps prose at 600px wide and scopes heading styles to this section — prevents accidental overrides elsewhere on the page.

Design Detail

The Strava Button

The approach

A regular HTML link styled with CSS to look like a Strava button — no library needed. Three things make it feel branded: the exact Strava orange, sharp corners, and a hard drop shadow.

<a href="https://www.strava.com/athletes/53854051"
   target="_blank"
   class="strava-btn">My Strava</a>

.strava-btn {
  background-color: #D4511E;     /* Strava's exact orange */
  color: white !important;
  padding: 12px 24px;
  border-radius: 0;               /* sharp corners */
  box-shadow: 3px 3px 0 #1C1915; /* zero-blur shadow */
  font-family: 'Barlow Condensed';
  letter-spacing: 0.15em;
  text-transform: uppercase;
}
1

#D4511E

Strava's exact brand color — the button reads as "Strava" before anyone reads the text.

2

border-radius: 0

Sharp corners match the athletic, direct tone of the page — rounded would feel out of place.

3

box-shadow: 3px 3px 0

Zero blur = hard-edged solid copy, not a soft glow. Gives the button a stamp-like, graphic quality.

Third-Party Media

Embedding Instagram & YouTube

The approach

Each platform provides an official embed code to paste into any webpage. These only work inside a {=html} block — Quarto strips iframes from regular Markdown sections.

<!-- Instagram: placeholder + runtime script -->
<blockquote
  class="instagram-media"
  data-instgrm-permalink="https://www.instagram.com/p/DWO0y71kTFG/"
  style="width:100%; max-width:540px;">
</blockquote>
<script async src="//www.instagram.com/embed.js"></script>

<!-- YouTube: 9:16 portrait iframe -->
<iframe width="315" height="560"
  src="https://www.youtube.com/embed/vY5WS2eHcCo"
  allowfullscreen></iframe>
1

Instagram: placeholder + script

The blockquote is a placeholder. embed.js loads on page open and replaces it with a live interactive post widget.

2

315×560 portrait

Exactly 9:16 — matches the YouTube Short format so it displays vertically, not as a widescreen box with black bars.

3

Why {=html} is required

Quarto removes <iframe> and <script> from Markdown sections. Inside a raw block, nothing gets stripped.

Visual Design

Design Choices

The intent

A tight palette used consistently — Strava orange appears only on key actions so it always draws the eye. Forest green and cream do all the atmospheric work without competing for attention.

Forest
#2C4A2E
Cream
#F5F0E8
Strava
#D4511E
Ink
#1C1915

Typography — styles.css

  • Playfair Display — h1/h2/h3; editorial, magazine quality
  • Barlow Condensed — body, labels, buttons; narrow and athletic
  • Wide letter-spacing on uppercase labels throughout
  • Defined once in styles.css, inherited by all pages

Why These Choices

  • Forest green = outdoors and endurance without a cliché sports color
  • Cream instead of white softens contrast — warmer overall tone
  • One accent color means it always stands out — no competition
  • Sharp corners throughout reinforce a direct, confident tone
Summary
